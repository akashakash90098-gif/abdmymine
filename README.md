# Leela Birthday Surprise ❤️

A small romantic advance-birthday surprise website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or use VS Code's Live Server extension.

## Deploy to Vercel
1. Create a new GitHub repository (for example `leela-birthday-surprise`).
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder (with all six photos) to the repository root.
3. In Vercel, choose **Add New → Project**, import that repository, and deploy.
4. Framework preset: **Other**. Build command: leave empty. Output directory: leave empty or `.`.

No build step or API keys are required. The Google Fonts import requires internet access; system fallback fonts are included.

## Customize
- Edit the birthday and personal message in `index.html`.
- Change colors in `:root` at the top of `style.css`.


## Birthday music
The `assets/birthday-melody.wav` file is an original, gentle instrumental melody. Visitors can start or pause it with the on-page music button; browsers generally require a user click before audio can play.
